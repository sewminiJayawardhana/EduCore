# EduCore 🎓

A modern, responsive educational institution website built with React and Vite. EduCore provides an elegant and user-friendly interface for showcasing educational programs, campus facilities, testimonials, and contact information.

## ✨ Features

- **Responsive Navigation** - Smooth scrolling navigation bar with mobile-friendly design
- **Hero Section** - Eye-catching landing section to capture visitor attention
- **Programs Showcase** - Display educational programs and offerings
- **About Section** - Information about the institution
- **Campus Gallery** - Visual showcase of campus facilities and environment
- **Testimonials** - Student reviews and feedback
- **Contact Form** - Easy-to-use contact form for inquiries
- **Footer** - Complete footer with relevant links and information

## 🚀 Tech Stack

- **React** (v19.1.0) - UI library for building interactive interfaces
- **Vite** (v7.0.4) - Next-generation frontend build tool
- **React Scroll** (v1.9.3) - Smooth scrolling functionality
- **ESLint** - Code linting and quality assurance
- **CSS3** - Custom styling for each component

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sewminiJayawardhana/EduCore.git
   cd educore
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` (or the port shown in your terminal)

## 📜 Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build production-ready application
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint to check code quality

## 🎨 Component Overview

### Navbar
Responsive navigation bar with smooth scrolling to different sections of the page.

### Hero
Engaging landing section that creates the first impression for visitors.

### Programs
Showcases the educational programs and courses offered by the institution.

### Title
Reusable component for section titles with subtitle support.

### About
Provides information about the institution's mission, vision, and values.

### Campus
Gallery section displaying campus facilities and environment through images.

### Testimonials
Displays student testimonials and reviews to build trust and credibility.

### Contact
Contact form for visitors to reach out with inquiries or feedback.

### Footer
Contains footer links, copyright information, and additional resources.
